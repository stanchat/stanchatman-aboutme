Quality review

2D and 3D digital media asset review checklist

This review structure helps an AI research workflow evaluate whether a creative asset is layered, exportable, readable at multiple sizes, and ready for downstream use.

2D asset checks

  • Vector shapes are separated from raster polish layers.
  • Palette is documented and applied consistently.
  • Icon remains readable in small/pixel preview.
  • Stroke width and opacity are explicit parameters.
  • Export targets include SVG and PNG variants.

3D / game handoff checks

  • 3D blockout communicates silhouette and material direction.
  • Asset name and purpose are clear.
  • Layer stack supports future editing.
  • Sprite/icon usage notes are documented for Godot-style handoff.
  • Review notes explain what is final versus conceptual.

How this maps to the survey tools

Relevant digital media tool patterns represented

  • GIMP: raster layer polish, opacity control, texture/shadow pass, PNG export thinking.
  • Inkscape: vector shapes, strokes, scalable SVG construction, icon design.
  • Krita: brush opacity, illustration polish, paint-over workflow.
  • Libresprite: pixel readability, constrained palette, small sprite preview.
  • Blender: low-poly 3D blockout, material direction, rotation/silhouette review.
  • Godot: game-ready sprite/icon handoff, asset naming, UI/game object notes.
